📱 About Gadget Point

Gadget Point is a complete e-commerce platform built with modern web technologies. Our feature-rich application provides:

🛍️ Shopping Features

· Product Catalog with 29+ electronics items across 8 categories
· Advanced Filters - Category, Price Range, Sorting (Price Low-High, Price High-Low, Rating)
· Real-time Search with instant results
· Product Details Popup with images, descriptions, and pricing
· Product Slider - Auto-slide with manual navigation controls
· Interactive Badges - New, Hot, Best, Sale indicators on products

❤️ User Engagement

· Rating System - Rate products with 1-5 stars
· Comments & Reviews - Share your feedback on products
· Wishlist - Save favorite items for later with remove option (🗑️)
· Order Tracker - Visual tracking (Ordered → Shipped → Delivered)

🛒 Cart Management

· Add/Remove Items with quantity controls
· Real-time Cart Updates with total calculation
· Coupon System - Apply discount codes (SAVE10, ELECTRO20)
· Confirm Order Button - Complete order process
· Persistent Storage - Cart saves across sessions
· Dustbin Icon 🗑️ - Easy remove from cart

🔐 Authentication & Profile

· Account Creation Mandatory - First create account to access website
· Login System with persistent sessions
· Logout Redirect - Logout ke baad Create Account page show
· Profile Page - Complete user dashboard
· Orders History - All orders with status (Delivered/In Transit/Pending)

· Edit Profile - Update name, email, phone number
· Change Password - Security feature
